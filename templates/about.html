About the System

Email Genuine/Fake Detection Using Machine Learning

Project Overview

The Email Genuine/Fake Detection System is a machine learning based web application designed to analyze email messages and classify them as True or False.

The system processes the entered email text, cleans the text and converts it into numerical features using TF-IDF. A Multinomial Naive Bayes model is then used to generate the classification result.

Along with the predicted result, the system displays the probability percentages for both True and False classifications.

How It Works

1. Email Input

The user enters or pastes an email message into the system.

2. Text Preprocessing

The email text is cleaned by converting it to lowercase, removing URLs, special characters and unnecessary spaces.

3. TF-IDF

The cleaned email is converted into numerical features using TF-IDF vectorization.

4. Machine Learning

Multinomial Naive Bayes analyzes the extracted features and predicts the result.

5. Probability

The system calculates True and False probability percentages for the email.

6. History

The classification result and probabilities are stored in the SQLite database.

Classification Results

The system provides two possible classification results:

TRUE FALSE

The result page displays both probabilities, for example True — 60% and False — 40%.

Technologies Used

Python Flask Scikit-learn TF-IDF Multinomial Naive Bayes SQLite HTML CSS

Project Features

Machine Learning

True Probability

False Probability

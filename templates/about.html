About the System

Email Classification System Using Machine Learning

Project Overview

The Email Classification System is a machine learning based application designed to automatically classify email messages into different categories.

The system processes the entered email text, converts it into numerical features using TF-IDF and applies a Multinomial Naive Bayes machine learning model to predict the appropriate category.

How It Works

1. Email Input

The user enters an email message into the system.

2. Text Processing

The email text is cleaned and prepared for machine learning.

3. TF-IDF

Important words are converted into numerical features using TF-IDF.

4. Classification

Multinomial Naive Bayes predicts the email category.
